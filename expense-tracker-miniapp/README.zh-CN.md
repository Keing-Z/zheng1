# 记账小程序 · 使用说明

一个**极简学生记账**微信小程序：3 秒记一笔，数据只存在本机，不需要服务器、不需要注册。

---

## 功能一览

| 页面 | 能做什么 |
|---|---|
| **记一笔** | 数字键盘直接输入金额、选分类、写备注，一屏搞定；保存后自动清空，可连着记下一笔 |
| **账单** | 按日分组查看，支持月份切换、分类筛选；长按记录删除（带确认） |
| **报表** | 环形图看支出结构、分类排行、近 6 个月趋势柱状图 |
| **我的** | 设置月度预算（超支标红）、连续记账天数、成就系统、导出备份 |

**设计取舍**：不做收入/多账本/云同步，只把"记一笔"做到最快——记账工具的死因是麻烦，不是功能少。

## 怎么跑起来（3 步）

### 1. 下载微信开发者工具

https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

### 2. 导入项目

打开开发者工具 → 导入项目 → 选择 `D:\money-ai\mini-book` 这个文件夹。

- **AppID**：先用 `测试号`（点"使用测试号"）就能本地预览，不需要注册；
- 如果配置界面要你填 AppID，选"测试号"或留空即可。

### 3. 编译运行

点顶部「编译」，模拟器里就能看到界面，键盘输入、记账、看报表都能直接操作。

## 想发给同学用（上线流程）

1. **注册小程序**：https://mp.weixin.qq.com → 立即注册 → 选「小程序」→ 个人主体即可（免费）；
2. 把拿到的 **AppID** 填进 `project.config.json` 的 `appid` 字段（替换 `touristappid`）；
3. 开发者工具里点「上传」，填个版本号；
4. 到 mp 后台「版本管理」提交审核 → 审核通过后点「发布」。

> 个人主体的记账工具有较大概率一次过审，但不要写"投资""理财""返现"这类词，会被驳回。

## 几个关键实现细节

1. **金额用「分」存整数**：`Math.round(金额 * 100)`，避免 `0.1 + 0.2 = 0.30000000000000004` 这类浮点误差。
2. **日期用本地时区自己拼**：不用 `toISOString()`，否则北京时间 0-8 点会算成前一天。
3. **环形图不用 canvas**：用 CSS `conic-gradient` 拼色段，性能好、无兼容问题、代码短。
4. **保存后自动清空**：让"记下一笔"零摩擦，这是坚持记账的关键。

## 已知限制（说清楚，不藏着）

- **数据只在本机**：卸载小程序或换手机，数据就没了。所以做了「导出备份」功能。
- **导入需要手动**：小程序本地存储隔离，无法直接读回导出的文本。如果真丢了，把备份文本发给我，可以写成脚本帮你还原。
- **没有收入记账**：当前版本按你的选择只做支出。以后想加，`store.js` 里已经预留了 `type` 字段。
