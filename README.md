## 我关心的三件事

- **说清楚"为什么"**：一个设计决策如果没有写清放弃了什么，那就只是猜测。每个仓库的 README 都写了选了什么、放弃了什么、下一步会改什么。
- **测试要找真 bug**：记账小程序里被测试抓出来的三个缺陷（CSV 丢列、文本顺序反转、备份恢复数据翻倍）都不是理论问题，都是用户会撞上的。
- **诚实报告**：结果不好看、限制没解决，就写下来。见蘑菇项目里对 100% 准确率的解释。
